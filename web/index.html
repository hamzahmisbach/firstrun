How it works

Peel
Hidden encoding such as base64 and gzip is decoded first, by plain code. Nothing has run yet. If plain code cannot open a layer, a model writes a small script that prints it instead of running it.
Run
The command runs exactly as pasted, on a fresh fake laptop with 35 fake secrets made for this run. Every site it tries to reach is answered by a recorder that forwards nothing. Everything is recorded from outside the sandbox, and the sandbox is destroyed afterwards.
Compare
Fixed rules compare what happened with what you were told. A fake secret leaving the sandbox is always malicious, whatever the story said.
Read, and try again
An AI also reads the code. It can raise a concern but never lower a verdict, and every reason has to quote code that really runs. If the code looks like it is waiting for something, FirstRun runs it once more with that condition met.

What a result does and does not mean

Clean is not safe

A clean result means nothing suspicious was seen in this run. It is not a promise that the command is safe on your machine.

Linux commands only

The sandbox is a Linux container, and Windows and macOS commands are refused. A script that behaves differently on those systems is only tested as Linux.

60 seconds, no internet

Every hostname leads to a fake server that records the request and answers nothing useful, so code the command would download is never fetched or seen.
